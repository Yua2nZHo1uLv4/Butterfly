# 仓库说明
神岛天梯S3《蝴蝶》仓库
# 策划案
## 玩法介绍
游戏采用LIM-Yua2nZHo1uLv4(13048840，即项目拥有者)的神岛2D引擎   
地图预设
每个章节内存在2个地点相同，时间不同的分支   
玩家同时操纵位于2个时间点的2个角色(赛事评委请注意，这里涉及的多人游戏，多人游戏是2人模式，2个都是自己)   
玩家需要操作2个不同时间的自己来解密，并探索事情的真相   
## 机制介绍   
位于过去的玩家会默认一直呆在现有位置，未来的玩家可以看到过去玩家的白骨   
过去的玩家可以实时影响未来的时间线(点题：蝴蝶，蝴蝶体现为蝴蝶效应)   
过去玩家的物品会随着时间放到玩家的白骨旁边   
玩家可以影响物品，也可以通过物品影响地图(或直接影响)   
物品无法直接被带到其他时间，只能通过遗留来传递
